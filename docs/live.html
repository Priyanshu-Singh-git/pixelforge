How it works

A tiny 2× network (Live: parameters, Lite: ) trained on game textures rendered at lower resolution. Every frame is grabbed, shrunk to the input resolution (as if the game rendered it there) and rebuilt at 2×. Models ship as ONNX, the same files mobile and game-engine runtimes load.
